# Dal CS|CD 
Dal CS|CD (Computer Science| Course Directory) is a website designed to help Dalhousie University Computer Science students explore and understand their course options more easily. It provides a searchable directory of courses with key details like descriptions, prerequisites, and shared feedback from other students about difficulty and time commitment
